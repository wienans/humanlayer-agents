# Canonical Evidence Resolution

The Research worker returns this shape. The Research skill publishes it as the Research record's single resolution.

```markdown
## Evidence

### Scope And Method

{Named sources inspected, versions or revisions when available, and source limitations.}

### Question Status

| Question | Status | Basis |
| --- | --- | --- |
| 1 | Established | {direct citations} |
| 2 | Unanswered | {where the named sources were insufficient} |

### Established Facts

#### 1. {Takeaway stated as a fact}

{Cohesive explanation with a citation for every material claim. Distinguish a direct observation from a clearly labeled inference.}

### Unanswered Questions

- **Question 2**: {what remains unknown and which named sources were checked}

Use `None.` when every question is established.

### Source Register

- `{path/to/file.ext:line-line}` - {facts supported}
- <https://primary.example/source> - {facts supported, version/date if relevant}
```

Use direct repository files, official documentation, specifications, standards, or upstream source as primary evidence. Cite precise lines, anchors, pages, or sections. Use a secondary source only when no primary source is available and label it as secondary.

Keep the resolution factual and non-normative. It contains no recommendations, preferred alternatives, criticism, implementation steps, or claims beyond the Named Sources.

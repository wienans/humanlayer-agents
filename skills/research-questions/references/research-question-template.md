# Research Packet

Use this body for an RPI Research record or return the same packet to Wayfinder.

```markdown
Role: Research

# Research: [Neutral current-state subject]

## Research Questions

1. Explain how [FEATURE] works end to end and all the systems involved
2. Explore the contract between [COMPONENT1] and [COMPONENT2] and how its implemented on both sides
3. Trace the flow of logic from [ENDPOINT] down to [DATASTORE]
4. Find all users of [DATABASE COLUMN or DATABASE TABLE] and what the data is used for

## Named Sources

(_Preserve high-signal pointers verbatim and define what may be inspected._)

- Links: [exact URL and permitted documentation scope] — Questions: [1, 2]
- Repositories: [repository name, revision when available, and permitted source scope] — Questions: [1]
- Libraries / dependencies: [package name, version when available, and permitted source scope] — Questions: [2, 3]
- Filepaths: [exact file or directory; directories include descendants only when stated] — Questions: [1, 3, 4]

## Source Boundaries

- Inspect only the named sources and their stated descendant scope.
- Retain unavailable or insufficiently evidenced answers as unanswered.
```

Do not include the originating request, desired outcome, proposed design, implementation plan, alternatives under consideration, or evaluation criteria that imply a preferred answer. Questions remain neutral when any answer could be useful.

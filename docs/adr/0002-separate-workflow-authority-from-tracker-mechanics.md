# Separate workflow authority from tracker mechanics

Source: [Define workflow vocabulary and artifact authority](https://github.com/wienans/humanlayer-agents/issues/6)

The workflow assigns authority by concern: evidence owns cited facts, Decision Tickets own resolved choices, Domain Documentation owns durable vocabulary and architecture, open Design Artifacts own approved intent, and each Delivery Ticket condenses its upstream sources into a self-contained tracer-bullet implementation contract. Closed tracker bodies remain historical and receive correction or supersession annotations rather than edits. Core skills use tracker-neutral operations and semantic roles through a context pointer to the Tracker Adapter generated by setup for GitHub, GitLab, local Markdown, or a user-described tracker; this preserves one source of truth per concern without making implementation reconstruct intent or coupling the suite to one tracker.
